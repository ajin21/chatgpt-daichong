## ChatGPT Plus 额度是多少？

额度可能按模型和功能分别计算，并可能调整。请以产品界面和 OpenAI 当前说明为准，不要把旧文章中的数字当成永久承诺。

## ChatGPT Plus 和 API 额度一样吗？

不是。Plus 是 ChatGPT 产品订阅，API 使用是另一套产品和计费方式。购买 Plus 不代表 API 账户获得余额或免费调用额度。

## ChatGPT Plus 可以取消吗？

请从本次订阅对应的付款渠道查看管理和取消选项。取消方式取决于你当时使用的入口；卸载 App 本身不会取消订阅。可参考 [OpenAI 取消 ChatGPT 订阅说明](https://help.openai.com/en/articles/7232927-canceling-your-chatgpt-subscription)。

## 扣款了但 Plus 没显示怎么办？

## 开通时需要提供 ChatGPT 密码吗？

不要向他人提供密码、邮箱验证码、支付验证码或其他可接管账号的凭证。使用任何第三方服务前，先核对其说明、账号要求、价格和售后规则。
